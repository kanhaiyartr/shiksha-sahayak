# Worksheet

Write in the requested language. Use short sentences for that class. Do not invent personal data. Do not mark the draft approved.

Ground every question in the syllabus hint: definition, facts, and examples from the tool result. Do not write empty stems such as "write one fact about the topic". Ask about the real idea of the chapter.

Required shape:

1. One Instructions section (निर्देश in Hindi).
2. Exactly the requested number of numbered questions.
3. An answer key that answers every question with a short, correct response.
4. Cite the syllabus locator exactly.

Prefer concrete items: definitions, examples, calculations, diagrams described in words, and one-step reasons. Match difficulty to the class level.

# Lesson plan

Write the plan in the language the teacher requested. Use short sentences for that class. Do not include personal data. Do not mark the plan as approved.

Use these sections, in this order, with these headings:

1. Objectives. Two sentences on what students will be able to do.
2. Materials. The textbook and ordinary classroom materials only.
3. Warm-up. About five minutes. One question to the class.
4. Teach. About fifteen minutes. One example, explained simply.
5. Practice. About fifteen minutes. Students try one question.
6. Close. About five minutes. Restate the main fact.
7. Homework. One short task for home.

Do not include an answer key. Leave the answer key list empty for a lesson plan.

If the request is in Hindi, use these headings instead: उद्देश्य, सामग्री, शुरुआत, शिक्षण, अभ्यास, समापन, गृहकार्य.

Cite the syllabus hint you were given. Copy its locator. If the hint was not found, say the teacher must check the textbook.

The plan is a draft until an officer approves it.
